# honala 视频的右上角

普通镜头、人物 B-roll、录屏、转场和片尾都关闭右上角频道水印。横屏和竖屏遵循同一规则，右上角可用于画面构图。画面内的产品标识、操作界面和来源署名照常显示。

## 更新旧工程

把当前组件模板的 `src/kit/ui.tsx` 合入工程，使用整期模板的工程也要同步 `src/lib/shell.tsx` 对应的固定转场。新版本兼容历史的 `<Brand />` 和 `brand` 参数，渲染时不显示频道角标。复用单独绘制角标的历史组件时，移除其中的频道叠层。

旧工程如果直接读取 `public/brand/` 里的频道 PNG，可从仓库根目录执行以下命令，用全透明图片替换该工程中的四个旧频道角标文件：

```sh
python3 skills/fred-remotion-output/scripts/install_brand.py /path/to/remotion-project
```

如果旧转场或片尾的水印已经烘入视频，选用干净源片或从可编辑工程重渲染。检查实际输出的普通镜头、混合镜头交界和转场帧。
